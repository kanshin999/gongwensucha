# 民国公文套语速查（通用版）

> 一个单页网页工具：输入即查民国公文套语，四步识读任意一篇民国公文。
> 87 条套语 · 四篇通用例文 · 1912—1928 年五版《公文程式》法规原文

无需安装、无需联网、无后端。下载即用，也可一键部署成在线站点。

---

## 这是什么

读民国档案，最先卡住的往往不是繁体字，而是**套语**——"等因奉此""仰""饬""未便""此批"。这些词不是废话，每一个都在标记公文的某个环节：引述、承接、命令、裁断、收束。

本工具把散在文书学著作里的解释，整理成一份可检索的对照表，并配了完整的法规原文与示例公文，供读档、备考、写作时随手查。

**适用**：历史学、档案学、文书学、法律史、地方史研究者与爱好者；近代史方向考研备考。

## 部署成在线版

任选一种，都是免费的。

### 1. GitHub Pages（推荐）

```bash
git init
git add index.html README.md LICENSE
git commit -m "init: 民国公文套语速查"
git branch -M main
git remote add origin https://github.com/<你的用户名>/minguo-gongwen.git
git push -u origin main
```

然后：仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main` / `(root)` → **Save**。

约 1—2 分钟后访问：`https://<你的用户名>.github.io/minguo-gongwen/`

### 2. Gitee Pages（国内访问更快）

仓库 → **服务 → Gitee Pages** → 部署分支选 `master` 或 `main` → 启动。
（需先完成实名认证）

### 3. Vercel / Netlify / Cloudflare Pages（免 Git）

- **Netlify**：打开 <https://app.netlify.com/drop>，把 `minguo-gongwen` 文件夹直接拖进去，即刻得到网址。
- **Vercel**：导入 Git 仓库，Framework Preset 选 **Other**，Build Command 留空，Output Directory 留空，直接 Deploy。
- **Cloudflare Pages**：上传文件夹，Build 输出目录填 `/`。

### 4. 自有服务器

把 `index.html` 放到任意静态目录（Nginx / Apache / 对象存储静态托管）即可。

## 自定义

### 增补套语

打开 `index.html`，找到 `const DATA = [`，按现有格式加一行即可：

```js
{t:"套语", p:"拼音", ab:"首字母", c:"分类", d:"释义", u:"用在哪", e:"例句", s:"出处", n:"辨析（可选）"}
```

字段说明：

| 字段 | 含义 | 示例 |
|---|---|---|
| `t` | 套语（显示为标题，可用 `/` 列多个变体） | `"等因"` |
| `p` | 拼音，无声调、空格分音节 | `"deng yin"` |
| `ab` | 拼音首字母（供快速检索） | `"dy"` |
| `c` | 分类：`A` 起首引述 / `B` 引据承接 / `C` 命令督促 / `D` 裁断结尾 / `E` 称谓自称 | `"B"` |
| `d` | 释义 | `"收束所引上级来文的结尾套语。"` |
| `u` | 用在哪（行文方向、环节） | `"引完上级训令，用它收口。"` |
| `e` | 例句 | `"……饬即查明灾情具报等因。"` |
| `s` | 出处（例文甲/乙/丙/丁，或"通用"） | `"例文甲"` |
| `n` | 辨析，可省略 | `"与等情、等由分工不同。"` |

> 注意：字符串统一用英文双引号包裹，内容中如需引号请用中文引号「」或“”，避免与 JS 语法冲突。

### 改配色

在 `:root` 中改 CSS 变量：

```css
--paper:#f7f3e9;   /* 纸色背景 */
--ink:#2b2622;     /* 正文墨色 */
--red:#a8322d;     /* 印章红（强调色） */
```

五类条目的标识色分别为 `--A` `--B` `--C` `--D` `--E`。

### 换例文

搜索 `例文甲`，替换 `<details>` 内的正文；把套语用 `<span class="tk" title="释义">套语</span>` 包起来，即可获得红色下划线与悬停提示。

## 内容说明

### 套语

共 **87 条**，按公文功能分五类：

| 分类 | 条数 | 内容举例 |
|---|---|---|
| A 起首与引述 | 16 | 案查、为…事、照得、案奉、案据、案准、窃、径启者、电悉 |
| B 引据与承接 | 22 | 等因、奉此、等情、等由、各在案、准此、据此、理合、相应 |
| C 命令与督促 | 14 | 仰、仰祈、饬、切切、即便、致于未便、有厚望焉、姑、暂 |
| D 裁断与结尾 | 28 | 呈悉、应准、未便、碍难、万难、应毋庸议、此令、此批、此致、谨呈 |
| E 称谓与自称 | 7 | 钧、大、职、敝、本、该、贵 |

### 例文

四篇**示例性虚拟公文**（非真实档案），覆盖四种行文方向：

- **甲** 上行：某县县长呈省民政厅（呈请拨发赈款）
- **乙** 下行：省民政厅训令各县（发放赈款）
- **丙** 平行：甲县咨乙县，附公函
- **丁** 布告：某县政府布告（河道疏浚）

### 法规原文

| 版本 | 名称 | 原文情况 |
|---|---|---|
| 1912.1 | 《临时政府公文程式》 | 全文 5 条 |
| 1912.11.6 | 《公文书程式》（教令第一号） | 节录前 12 条 |
| 1914.5.26 | 《大总统公文程式令》等三令 | 大总统令全文 11 条＋另二令文种清单 |
| 1916.7 | 《公文程式》 | 13 种文种 |
| 1928.11.15 | 《公文程式条例》 | 全文 6 条 |

> 常见讹传：有文章称《公文程式条例》"1927 年 11 月 15 日公布"，实为**民国十七年（1928）11 月 15 日**。1927 年 8 月另有首颁版本（10 种），勿混。

## 资料来源与免责

- 法规原文据《临时政府公报》《政府公报（北洋政府）》及维基文库校录；条文以竖排原件用字为准（如"左列"不改）。
- 套语分类框架参照汪海涛《如何识读民国公文档案？》（中国第二历史档案馆）提出的十二类用语体系，并作合并与补充。
- 例文为示例性虚拟公文，**非真实档案**，仅用于演示套语用法，不可作为史料引用。
- 本工具为学习辅助，释义为常见用法归纳，具体文书中的含义仍需结合上下文判断。
